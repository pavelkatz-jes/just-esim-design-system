# Photos

Фото предметов и направлений на белом фоне — с прода.

- `bird.webp` 740 × 730, `pizza.webp` 450 × 450, `ball.webp` 450 × 450 — изображения карточек преимуществ (до 370, 346 и 297 в ширину); текстовый блок наезжает на них снизу.
- `card-cd.webp` (Конго), `card-nl.webp` (Нидерланды) — фото для карточки продукта: кадрируются в правый верхний угол шириной 270 с `mix-blend-mode: multiply`, поэтому фон фото должен быть белым.
