# Шрифт

Haffer Medium 500 (Displaay) — лицензионный шрифт, поэтому файла в репозитории нет. Шрифт выдаёт дизайн-команда.

- Установите шрифт в систему — `tokens/tokens.css` найдёт его по имени (`Haffer Medium`, `Haffer-Medium`).
- Или положите сюда `HafferMedium.woff2`. Папка в `.gitignore`: файл не попадёт в коммит.

Без шрифта текст показывается запасным стеком `--font-primary`.
