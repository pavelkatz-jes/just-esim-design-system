# Презентации

Гайд презентации не описывает — раздел собран из общих правил и прода. Все девять типовых слайдов собраны на странице `components/Slides/preview.html`.

## Холст и сетка

- Размер `slide-width` × `slide-height` — 1920 × 1080 (16:9).
- Поля: `space-24` 96 слева и справа, `space-20` 80 сверху и снизу.
- 12 колонок (`slide-columns`), промежуток `space-6` 24, ширина колонки `slide-column` 122.
- Фон всех слайдов — `color-main`. Группы контента — в белых карточках `Card` с паддингом 48 (`space-12`), код и терминал — в `DarkCard`.
- Логотип обязателен на обложке и финальном слайде; на остальных — по необходимости: `LogoTile` 48 в левом верхнем углу по полю.
- Номер слайда — `slide-caption` цветом `text-caption`, в правом нижнем углу по полю.

## Шрифт и цвет в редакторах

- Haffer встраивается в файл. Если носитель этого не позволяет (Google Slides), берите ближайшую доступную замену — Inter Medium.
- Где нет прозрачности, ставьте сплошные цвета: `solid-primary-on-main` вместо `color-primary`, `solid-secondary-on-main` вместо `color-secondary`, `solid-caption-on-main` для подписей; на белых карточках — варианты `*-on-white`.

## Шкала текста

Минимальный кегль на слайде — 24.

| Стиль | Размер | Роль |
|---|---|---|
| `slide-number` | 200 / 92%, −0.04em | крупная цифра |
| `slide-display` | 160 / 92%, −0.03em | обложка, разделитель |
| `slide-title` | 96 / 92%, −0.03em | заголовок слайда |
| `slide-lead` | 42 / 120% | подзаголовок, тезис |
| `slide-card-title` | 42 / 105% | заголовок карточки |
| `slide-body` | 32 / 120% | основной текст |
| `slide-caption` | 24 / 120% | подписи, источники, номер слайда |

## Типовые слайды

| Слайд | Композиция |
|---|---|
| Обложка | `slide-display` до трёх строк слева, справа фирменный объект (стекло) или мокап телефона, внизу `slide-caption` с датой и автором |
| Разделитель | номер раздела (`slide-caption`, `text-caption`) и `slide-display` |
| Тезис | `slide-title` сверху слева, под ним `slide-lead` цветом `color-secondary`; ширина текста до 8 колонок; ключевые слова — `<b>` цветом `ink` |
| Карточки | `slide-title` и 2–4 белые карточки в ряд: иконка 32, `slide-card-title`, `slide-body` цветом `color-secondary` |
| Цифры | 1–3 цифры в ряд: `slide-number`, под каждой `slide-caption` цветом `color-secondary` |
| Список | чек-лист: строки `slide-body`, заливная иконка 32, разделители `line` |
| Таблица | `slide-title` и таблица в белой карточке: заголовки `slide-caption` цветом `text-caption`, строки `slide-body`, разделители `line` |
| Продукт | мокап телефона или `ProductCard` (бейдж данных, чипы тарифов) и 1–3 строки текста |
| Финал | `slide-title`, под ним XL-кнопки (`StoreButtons`) или контакты (`slide-body`) |

## Правила

- Одна мысль на слайд, основного текста — до 40 слов.
- Один акцент на слайд: либо градиентное слово или бейдж (`grad`, `grad-solid`), либо дополнительный цвет.
- Графики: основная серия `chart-1`, остальные — `chart-2` и `chart-3`; ключевое значение можно выделить `chart-key`; подписи — `slide-caption` цветом `color-secondary`, сетка — `chart-grid`. Без 3D, теней и градиентов.
- Изображения — только фирменные ассеты (`assets/Glass/`, `assets/Logos/`) и фото (`assets/Photos/`).
