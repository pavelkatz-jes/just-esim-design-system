# DarkCard

Тёмная поверхность `surface-dark` с радиусом `radius-inner` для кода, терминала и тёмных карточек на слайдах.

**Что передаёт потребитель:** `title` — подпись сверху (`text-on-dark-secondary`, 14 px), `code` — строка кода (моноширинный 16 / 24, переносы сохраняются) или произвольное содержимое в `children`.

**Правила:**
- Основной текст — `text-on-dark` (16.4:1), вторичный — `text-on-dark-secondary` (5.3:1).
- На главной прода не встречается — используйте для документации, кабинета, презентаций.
- Паддинг 24 и кегль кода гайдом не заданы; взяты шаги `space-6` и `text-base`.
