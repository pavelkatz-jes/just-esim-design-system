# StoreButtons

Пара XL-кнопок App Store и Google Play: контейнер `store-buttons-width` 600, промежуток 16, кнопки делят ширину поровну; на mobile — столбиком с отступом 16.

**Что передаёт потребитель:** ссылки `appStoreHref`, `googlePlayHref` (по умолчанию — карточки приложения в сторах) и подписи, если нужен перевод.

Ставьте под заголовком секции («One eSIM / The whole world») или на финальном слайде. Одна пара на экран.
