# LogoTile

Компактный логотип Just eSIM на плитке с тенью `shadow-logo` — точные контуры знака из `/favicon.svg`.

**Что передаёт потребитель:** `size` — 48 (шапка, радиус 16) или 56 (мобильное меню, радиус 14), `tone` — `light` или `dark`, `href` — ссылка на главную (без неё плитка — картинка), `label` — подпись для скринридера.

**Тона:**
- `light` — плитка `surface-tile` с белой обводкой .4 и знаком .9, как в файлах прода.
- `dark` — белый знак на `surface-grey` (гайд), для тёмных фонов.

Знак без плитки — `LogoMark` (`tone` `dark` / `white`, `height` в px). Логотип не перекрашивают, не обводят и не кладут на градиент.
