# ProductCard

Карточка eSIM из приложения: радиус 24, обводка 0.5 px, поля 16 24, до 340 в ширину и от 100 в высоту; нажатие — scale .95 и opacity .8.

**Что передаёт потребитель:** `country` (22 / 130%), `meta` — срок (14 / 130%, `color-secondary`), `data` — остаток для бейджа, `state` — `active` или `expired`, `photo` — фото страны, `plans` — чипы под истёкшей карточкой, `tilt`, `onClick`.

**Состояния:**
- `active` — фон `surface`, белая обводка, `shadow-big`, бейдж данных справа сверху; справа у названия поле 80 под бейдж.
- `expired` — фон `surface-expired`, обводка `stroke-field`, снизу градиент `expired-gra`; название `text-inactive` (4.1:1 на этом фоне — как в проде), срок с `opacity-expired` .7; снизу чипы `PlanChip`.

**Фото:** белое фото, связанное со страной, кадрируется в правый верхний угол шириной 270 с `mix-blend-mode: multiply`.

**Композиция:** `ProductCardStack` кладёт две карточки как на главной — активную сверху слева с наклоном 1.5°, истёкшую ниже справа с −3°. Наклон — только в таких композициях «предметов».
