# SelectField

Поле выбора виджета покупки: белое, обводка 1 px `stroke-field`, радиус `radius-inner`, от 88 в высоту, поля 16 20; справа `chevron-circle` 20 цветом `text-service`.

**Что передаёт потребитель:** `label` — подпись 14 / 20 `color-secondary` («Country or region»), `value` — значение 32 px `ink` в одну строку («Andorra»), `onClick` — открыть список.

Длинные значения обрезаются многоточием. Иконка-шеврон `text-service` (1.6:1) декоративна: поле узнаётся по обводке и подписи.
