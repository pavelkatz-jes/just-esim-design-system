# GlassStack

Стопка из трёх стеклянных плиток над «One eSIM / The whole world»: верхняя прямо, нижние повёрнуты на −10° и 15° и сдвинуты в стороны.

**Что передаёт потребитель:** `images` — три плитки из `assets/Glass/` (верхняя, левая, правая) и `alts`.

Занимает 50% ширины колонки, под ней отступ 40 и H2. Тёплое пятно `#FFEAD2`, которое на главной стоит за этой стопкой, в новые макеты не переносим.
