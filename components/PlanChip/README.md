# PlanChip

Белый чип тарифа высотой 40 (`chip`) с тенью `shadow-big` и текстом 16 px — ряд чипов под истёкшей карточкой продукта.

**Что передаёт потребитель:** `label` — тариф («10 GB»; «∞» рисуется градиентом 24 px), `icon` — `plus` (добавить), `dots` (ещё варианты) или `null`. Без `label` чип становится круглым по содержимому с полями 16.

Чипы стоят в ряд с промежутком 4 и делят ширину поровну; последний — `icon="dots"` без текста.
