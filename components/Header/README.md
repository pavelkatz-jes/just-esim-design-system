# Header

Шапка сайта: фиксированная, поля 24 16 40, контейнер до 1212. От 1280 — плитка логотипа 48 и выбор языка слева, пилюля навигации по центру, кнопка M справа; до 1280 — бургер 32 и кнопка M.

**Что передаёт потребитель:** `links` — пункты навигации, `language` — свойства `LanguageSelect`, `cta` (по умолчанию «Download app» с глифом платформы: `apple`, `google-play` или `download`), `scrolled` — показать подложку, `position` — `fixed` или `static`, `layout` — `auto`, `desktop`, `mobile`, `onMenu` — открыть `MobileMenu`.

**Детали:**
- Пилюля навигации — `glass`, высота 48, поля 0 24, промежуток 30, ссылки 16 / 24 `ink`.
- При прокрутке под шапкой проявляется `menu-gra` за 150 ms; на лендингах — того же цвета, что `color-bLanding`.
- Кнопка в шапке одна; другие действия — в контенте.
