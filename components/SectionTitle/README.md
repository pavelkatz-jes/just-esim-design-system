# SectionTitle

H2 секции: 80 px на desktop, 8vw от 640, 48 на mobile; интерлиньяж 92%, трекинг −0.03em, цвет `ink`, до контента 40 (на mobile 32).

**Что передаёт потребитель:** текст — обычно две короткие строки через `<br/>`, `align` (`center` по умолчанию, `left` — для отзывов и реферального блока на mobile), `as`.

Одно слово можно залить `GradientText` («Earn 3 €»), если на экране нет другого акцента.
