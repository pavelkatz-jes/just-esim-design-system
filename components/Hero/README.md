# Hero

Первый экран: стеклянный элемент по центру, под ним H1 148 px (14vw на mobile), который на desktop наезжает на изображение на −200; ниже лид `text-bd` и виджет покупки в ряд с промежутком 48.

**Что передаёт потребитель:** `image` (desktop, до 700), `imageMobile` (80% ширины, до 400), `title` — две строки через `<br/>`, `lead` (`color-secondary`; на mobile 22 px по центру и отступ 64), `aside` — обычно `PurchaseWidget`.

На mobile сверху отступ 112 под фиксированную шапку. Один H1 на страницу.
