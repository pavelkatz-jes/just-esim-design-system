# Segmented

Сегментированный переключатель срока и объёма: дорожка `fill-track` с обводкой `stroke-field`, радиус 40, поля и промежуток 4; сегменты 44 в высоту, радиус 24, текст 18 / 28 `color-primary`.

**Что передаёт потребитель:** `options` (`value`, `label`), `value` / `defaultValue`, `onChange`, `label` для скринридера.

Выбранный сегмент — `glass` с обводкой 0.5 px `stroke-field`, переход 100 ms. Два переключателя подряд разделяет 8. Сегментов — 2–4 коротких значения («7 days», «1 GB»).
