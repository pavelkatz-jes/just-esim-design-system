**Что передаёт потребитель:** `items` (`question`, `answer` — текст или разметка с абзацами, списками и ссылками), `defaultOpen`, `title`, `action` — обычно `Button` L «See all answers».

Ответы `text-muted` — 4.0:1, ниже AA для мелкого текста (как на проде); длинные важные ответы лучше выносить на страницу FAQ.
