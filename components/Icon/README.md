# Icon

Заливной глиф из набора прода; красится через CSS `color` (`currentColor`), по умолчанию — родной размер (около 20 × 21).

**Что передаёт потребитель:** `name` — имя глифа, `size` — высота в px (ширина масштабируется), `title` — подпись, если иконка несёт смысл без текста (иначе она скрыта от скринридера).

**Набор:** кнопки (`apple`, `google-play`, `download`, `lightbulb`, `person-plus`), шапка и формы (`burger`, `chevron-down`, `chevron-circle`, `sparkles`), карточки (`pie-chart`, `bell`, `first-aid`, `clock`, `person`, `devices`, `smile`), списки и тарифы (`check-circle`, `plus-circle`, `dots`, `copy`), cookie-баннер (`check`, `back`, `gear`), платёжные системы `pay-*` и соцсети `social-*` в своих цветах.

**Правила:**
- Цвет — `ink` или наследуемый; служебные стрелки и уголки — `text-service`.
- Линейных иконок в бренде нет, кроме галочки чекбокса и plus в FAQ.
- Не добавляйте эмодзи и стоковые 3D-иконки. Файлы глифов — `assets/Icons/`.
