# CookieBanner

Cookie-баннер: оверлей `overlay-cookie`, белая карточка с радиусом 20 и паддингом 24, до 910; на mobile прижата к низу, на desktop стоит по центру.

**Что передаёт потребитель:** `title` (18 / 28 `ink`), текст в `children` (16 / 24 `gray-500`, ссылки `color-aqua`), подписи и обработчики «Customize», «Recommended» (secondary M) и «Accept all» (primary M).

Служебные цвета `gray-500` и `color-aqua` используются только здесь; `color-aqua` на белом — 2.9:1, как на проде. На mobile кнопки идут столбиком, главная — сверху.
