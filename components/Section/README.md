# Section

Секция страницы: боковые поля `space-4`, колонка `content` 1024 по центру, вертикальные отступы `space-36` 144 на desktop и 16vw на mobile.

**Что передаёт потребитель:** содержимое и `id` — якорь со смещением под фиксированную шапку (−40, на desktop −120).

Внутри: `SectionTitle`, отступ 40 и контент. Соседние секции схлопывают отступы — между ними ровно 144.
