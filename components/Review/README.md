# Review

Отзыв в карточке с паддингом 24 (32 от 768): сверху пять звёзд `color-star`, текст 16 / 140% `color-secondary` с абзацами через 8, внизу имя 32 px, страна 16 px с флагом и ссылка перевода.

**Что передаёт потребитель:** `paragraphs`, `name`, `country`, `flag` (круглый флаг 16), `translation` — текст, имя и страна на английском; тогда появляется «View Translation» / «View Original».

Отзывы стоят сеткой в 2 колонки от 1024 с промежутком 12 / 16 / 24. Текст публикуется как есть, эмодзи автора сохраняются. Ссылка перевода — `color-accent1` при 80% с точечным подчёркиванием (3.4:1, как на проде).
