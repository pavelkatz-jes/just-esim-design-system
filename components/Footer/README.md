# Footer

Футер: отступ сверху 32, поля 24, снизу 32 на mobile и 24 на desktop; три колонки от 1024 с промежутком 32, на mobile — столбиком.

**Что передаёт потребитель:** `columns` (`title`, `links`), `copyright`, `email`, `version`.

**Детали:** заголовок колонки 14 px `text-caption`, отступ 20; ссылки `text-b` `ink`, поля 16, разделитель `line`, у последней ссылки разделителя нет; внизу копирайт и почта 14 px `color-secondary`, версия 12 px `text-service`.
