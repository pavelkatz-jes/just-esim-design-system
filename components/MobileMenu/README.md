# MobileMenu

Мобильное меню — bottom sheet на `color-main` с радиусом 44 сверху: выезжает снизу за .3s (`ease-out`), оверлей `overlay-modal`.

**Что передаёт потребитель:** `links`, `languages` (коды выводятся капсом с флагом 32), `cta`, `open`, `onClose`, `inline` — в потоке для макетов.

**Порядок:** плитка логотипа 56 и отступ 80; ссылки `text-big` с промежутком 36; языки; отступ 48; кнопка M на всю ширину. Кнопка закрытия — как у `Modal`.
