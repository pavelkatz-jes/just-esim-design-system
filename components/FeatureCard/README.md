# FeatureCard

Карточка преимуществ: изображение или «предметы» сверху, текстовый блок наезжает на изображение на 80 px; заголовок `text-big`, описание `text-b` `color-secondary`, кнопка L на всю ширину.

**Что передаёт потребитель:** `image`, `imageWidth`, `imagePosition` (`center` / `start`), `overlap`, `title`, `description`, `features` (иконка + текст), `align` (`center` — по центру, `left` — влево, тогда фон `white`), `action`, `cornerIcon`, `balance`, своё наполнение в `children`.

**Три типа (прод):**
- Изображение, под ним заголовок и описание по центру, secondary-кнопка L.
- Карточки продукта (`ProductCardStack`) и `ListRows`.
- Изображение, заголовок, пункты с иконками (отступ 12 до текста), primary-кнопка L.

Паддинг карточки 16, текстового блока ещё 10. Сетка — `FeatureGrid`: 2 колонки от 1024 с промежутком 24 (500 + 500), на mobile столбиком с промежутком 8.
