# ListRows

Строки внутри карточки: `text-xl` `ink`, глиф 20 справа от текста, разделители `line`, отступы 20; пояснение под строкой 14 / 1.2em `text-caption`.

**Что передаёт потребитель:** `rows` — `label`, `hint` (необязательно), `icon`.

Используйте для 2–4 возможностей продукта («Track your expenses», «Limit notifications»). У последней строки разделителя нет.
