# GradientText

Заливка текста фирменным градиентом `grad` (90°, `#DF0C99 → #4D4DE9` при .9) — класс прода `.gra`.

**Что передаёт потребитель:** текст и тег `as`.

**Где:** одно слово или число в заголовке («Earn 3 €»), промокод («NX2025»), знак «∞» в чипе тарифа.

**Правила:**
- Один градиентный элемент на экран или слайд.
- Только крупный текст: от 24 px контраст концов градиента — от 3.4:1 на `color-main`.
- Не заливайте градиентом фоны, кнопки, иконки и графики.
