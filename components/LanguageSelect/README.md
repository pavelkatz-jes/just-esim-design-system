# LanguageSelect

Выбор языка: высота 48, поля 0 16, промежуток 8 — круглый флаг 16, название 18 px и шеврон; список — белый, радиус 12, поля 12 16, промежуток 12, текст 18 / 18.

**Что передаёт потребитель:** `current` и `options` (`code`, `label`, `flag`, `href`), `open` / `defaultOpen`, `onSelect`.

Список появляется за .3s: `translateY(-5px) rotateX(-15deg)` → 0, шеврон переворачивается. Шеврон на проде цвета `text-service` (1.6:1) — декоративный, состояние передаётся `aria-expanded`.
