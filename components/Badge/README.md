# Badge

Пилюля высотой 36 с текстом 22 px и обводкой `stroke-badge`: объём данных на карточке продукта или градиентный бейдж из гайда.

**Что передаёт потребитель:** текст и `tone`.

**Тона:**
- `data` (прод) — `accent-green` на `accent-green-dark`, 5.9:1. Только объём данных: «11.2 GB». В карточке продукта стоит в правом верхнем углу (top 16, right 10).
- `gradient` (гайд) — белый текст на `grad-solid`, например «25% с каждой покупки». Размеры повторяют бейдж данных — в гайде они не заданы.

`accent-green` не используется вне этого бейджа; градиентный бейдж считается единственным акцентом экрана.
